# Recherche — blocage des pubs YouTube (état au 2026-10-19) et navigateur Orion

Agent de recherche, 2026-10-19. V = vérifié sur source primaire, R = rapporté, S = supposé.

## A. YouTube

- **Listes par défaut de Brave** (V, `brave/adblock-resources/filter_lists/list_catalog.json`) : « Brave Default Adblock Filters » = uAssets `filters.txt`, `filters-2020…2026`, `filters-general`, `badware`, `resource-abuse`, `unbreak`, `quick-fixes`, `ubo-link-shorteners` + EasyList + urlhaus + listes Brave (`brave-unbreak`, `brave-specific`, `brave-social`, `brave-sugarcoat`…) ; « Privacy » = EasyPrivacy + uAssets `privacy.txt` ; « First Party » ; visibles par défaut : Cookie notice blocker (fanboy cookiemonster + uAssets `annoyances-cookies` + brave-cookie-specific) et Mobile app promo. Fanboy Annoyances n'est **pas** dans le défaut. Optionnelles : `experimental.txt` Brave, YouTube Shorts blocker, etc.
- **uBO par défaut** (V, `gorhill/uBlock/assets/assets.json`) : `ublock-filters`, `badware`, `privacy`, `unbreak`, `quick-fixes`, EasyList, EasyPrivacy, urlhaus, Peter Lowe ; URL `https://ublockorigin.github.io/uAssets/filters/<nom>.txt`. Le préréglage Ghostery `adsAndTrackingLists` couvre l'essentiel (filters 2020-2024, privacy, unbreak, badware, quick-fixes, resource-abuse, EasyList, EasyPrivacy, Peter Lowe) — **vérifier qu'il inclut filters-2025/2026 ; sinon les ajouter via `fromLists` avec des URL explicites**.
- **Mécanismes YouTube** (V, `filters.txt` et `quick-fixes.txt`) : scriptlets `trusted-replace-xhr-response "adPlacements"→"no_ads"`, `trusted-replace-fetch-response` (adPlacements, adSlots sur `player?`), `set-constant undefined` sur `ytInitialPlayerResponse.playerAds/adPlacements/adSlots`, `json-prune`, `json-prune-fetch-response … propsToMatch /\/player(\?|$)/`, `nano-stb`, et des `trusted-edit-inbound-object` qui falsifient `attestationRequest` (lecture liée à une attestation client) ; règles réseau `$replace` actives seulement sous `cap_html_filtering` (Firefox) → ne pas compter dessus. Les scriptlets `trusted-*` ne s'exécutent que depuis des **listes de confiance** : s'assurer que le moteur les exécute (le spike a vu `trustedReplaceXhrResponse` injecté → OK avec Ghostery).
- **Cadence** (V) : `quick-fixes.txt` expire à 8 h, ~45 correctifs « update #30157 » entre février et octobre 2026 (≈ 1 par semaine) ; uAssets #30157 « ALL YouTube issues » ouvert depuis 2025-09-24 ; symptômes 2026-10 : faux buffering 4-24 s, popup « Experiencing interruptions? ». → **Lyra doit rafraîchir quick-fixes toutes les 4-8 h** (ETag / If-Modified-Since), au démarrage, avec bouton manuel et date visible.
- **Brave** (V) : casses et réparations en mai, juin, juillet, août 2026 (`brave-specific.txt` : SABR fixes) ; bug adblock-rust #679 : un scriptlet `json-edit` dans une liste faisait réapparaître les pré-rolls (bug brave-core) → tester les scriptlets inconnus avec Ghostery ; brave-browser #58360 (écran anti-adblock, fermé « not planned », renvoi vers #30157). Pas de « bloqueur YouTube dédié » chez Brave : listes uBO fusionnées + experimental. Au-delà des listes : randomisation du fingerprinting, cookies tiers bloqués, referrer réduit.
- **SSAI** : test signalé en juin 2024 (SponsorBlock) ; aucune preuve de déploiement général en 2026 ; les correctifs 2026 visent toujours `adPlacements`/`adSlots` côté client (S).
- **Risques** : casse hebdomadaire sans pipeline de mise à jour ; règles d'attestation fragiles ; ToS (aucun cas de bannissement documenté).
- **Reco test** : rejouer le test « 5 vidéos enchaînées, 0 pré-roll, pas de faux buffering » à chaque mise à jour de liste (CI optionnelle, dépend du réseau).

## B. Orion (Kagi)

- **Kagi a arrêté Orion pour Linux et Windows le 2026-10-02** (V, blog.kagi.com/update-orion-linux-windows) ; code des deux ports à publier (licence inconnue) ; macOS/iOS continuent. → Lyra occupe une niche vide sur Windows.
- Extensions : Chrome et Firefox sur WebKit, ~70 % des API WebExtensions, en bêta, « une API manquante suffit à casser une extension », 20 extensions garanties, `window.KAGI` pour détection, permissions par site, mode compatibilité par site (V).
- Zéro télémétrie ; bloqueur intégré par défaut (ITP + EasyPrivacy + listes), revendique 99,9 % des pubs YouTube ; anti-fingerprinting par blocage de scripts ; **aucun moteur de recherche par défaut** (choix au premier usage, `%s`, mots-clés Quick Searches) (V).
- UI : onglets verticaux (sidebar repliée en icônes, dépliée au survol), **pas d'arbre d'onglets documenté** (groupes « Named Windows », Compact Tabs dans la barre d'adresse, mini toolbar), Focus Mode ⇧⌘F (bordure colorée en 1.1), Link Preview (⇧clic), Profils (couleur, raccourci, données séparées), containers par onglet (1.1), Orion+ (5 $/mois), Low Power Mode (suspend après 5 min), mode lecture ⇧⌘R, synchro (fichier d'abord sur Windows), Orion Keychain, raccourcis macOS, import Safari/Chrome/Firefox/Edge au premier lancement (V/R).
