## Global Constraints
- **Aucune fenêtre visible** (consigne impérative de l'utilisateur) : tests e2e et captures uniquement via la config Playwright (`LYRA_TEST=1` → fenêtres cachées, `src/main/modeTest.ts`) ; jamais `LYRA_E2E_VISIBLE`, jamais `npm run dev`, jamais l'app empaquetée à l'écran.
- Respect strict du design validé : libellés, valeurs par défaut, couleurs hexadécimales et ordre des lignes copiés des trois `.dc.html` ; aucun réglage inventé, aucun réglage du design omis (un réglage non encore appliqué est affiché **inerte** avec la mention « bientôt », jamais caché).
- `settings.json` : `version: 2`, migration 1 → 2 idempotente dans `validate.ts`/`store.ts`, un réglage inconnu est ignoré sans casser le fichier, un réglage absent reçoit sa valeur par défaut ; export/import JSON existants préservés (un export v1 s'importe).
- Thèmes = variables CSS poussées par IPC à toutes les vues (ciel, capsule, overlay, pages `lyra://`), jamais de rechargement de page ; changement de couleur visible en moins d'une image.
- Règles par site : résolution « la règle la plus précise gagne » (origine exacte > hôte > motif `*.hôte`) dans un module pur `src/main/settings/sites.ts` testé ; application dans `Shields`, `Permissions`, `TabManager`, le preload `page` et `session.webRequest` par ajouts localisés.
- Fichiers partagés avec B/C/E (`src/main/index.ts`, `src/shared/ipc.ts`, `src/shared/types.ts`, `src/main/settings/{defaults,validate}.ts`, `src/renderer/ui/Capsule.tsx`, `MenuPanel.tsx`) : ajouts localisés seulement, jamais de refonte ni de renommage.
- Machine Windows à mémoire basse : vitest `--no-file-parallelism`, un seul e2e à la fois. Ne jamais lire les vrais profils de l'utilisateur.

## Review Focus
1. Migration : un `settings.json` v1 réel (celui produit par le jalon A/cycle 2) devient v2 sans perte, l'export JSON reste importable, un fichier corrompu redonne les défauts avec un avertissement, un réglage inconnu survit à une réécriture.
2. Couleurs : changer « Ciel — fond » en sombre met à jour le ciel, la capsule, les pages `lyra://` et le nouvel onglet immédiatement ; une paire texte/fond sous 4,5:1 est signalée et la correction proposée respecte 4,5:1 ; « Mes couleurs » se marque « modifié » dès une couleur changée et un thème prêt restaure toutes ses valeurs.
3. Passage en sombre : « Avec le système » suit `nativeTheme`, « À une heure fixe » bascule à l'heure dite (horloge injectable en test), « Au coucher du soleil » utilise une position approximative sans réseau (fuseau horaire → table) et jamais la géolocalisation.
4. Règles par site : sur `youtube.com` avec Boucliers « Strict » + scriptlets YouTube, cookies « 1re partie », zoom 100 %, style perso : la page reçoit le style **avant son premier rendu**, les cookies tiers sont refusés, le zoom est appliqué ; sur un sous-domaine, la règle `*.hôte` s'applique et la règle exacte la supplante ; supprimer la règle rend le comportement par défaut sans redémarrage.
5. User-agent par site et lecture automatique : l'UA alternatif n'est envoyé qu'aux requêtes du site (`onBeforeSendHeaders` filtré par origine de la frame), `navigator.userAgent` concorde ; « Bloquer » la lecture auto empêche `play()` non déclenché par l'utilisateur, « Sans le son » force `muted`.
6. Aucune régression : suites vitest et Playwright vertes, test `@youtube` vert avec une règle Strict sur youtube.com, aucune fenêtre visible.

### Task 4 : règles par site — modèle, résolution et application
`src/shared/types.ts` : `RegleSite` étendu (ajouts) — `boucliers: 'desactives' | 'standard' | 'strict'` (migration de l'ancien booléen : `false` → `'desactives'`, absent → `'standard'`), `scriptletsYoutube?: boolean`, `cookies?: 'tous' | 'premiere-partie' | 'bloques' | 'session'`, `scripts?: 'autorises' | 'bloques'`, `extensions?: string[] | 'toutes'` (crochet jalon B), `lectureAuto?: 'autoriser' | 'sans-son' | 'bloquer'`, `ua?: string` (profil nommé : « Lyra (Chrome 152) » par défaut, autres profils dans `src/shared/ua.ts`), `style?: string`, `scripts_perso?: Array<{ nom, code, actif }>`, `exceptionDnd` (jalon C), `permissions` et `zoom` existants. `src/main/settings/sites.ts` (pur, testé) : clés acceptées (origine exacte, hôte, motif `*.hôte`), `resoudre(url): RegleEffective` avec « la règle la plus précise gagne » champ par champ, cache invalidé à chaque écriture, IPC `sites:lister/ecrire/supprimer`. Application : **Boucliers** (`Shields.ts` lit le niveau par site : désactivé = pas de filtrage, strict = listes de gênes + blocage des scripts tiers inconnus ; scriptlets YouTube par site) ; **cookies** (`onHeadersReceived` retire `Set-Cookie` tiers ou tous selon la règle, `session.cookies` purge les cookies « Session seulement » à la fermeture) ; **scripts** (`onHeadersReceived` ajoute `Content-Security-Policy: script-src 'none'` pour « Bloqués ») ; **zoom** existant ; **lecture automatique** (preload `page` : surcharge de `HTMLMediaElement.prototype.play` hors geste utilisateur, `muted` forcé pour « Sans le son ») ; **UA** (`onBeforeSendHeaders` filtré par l'origine de la frame principale + `navigator.userAgent` cohérent via `webContents.setUserAgent` à la navigation) ; **style personnalisé** (« Appliqué à chaque page du site, avant son premier rendu » : preload `page` injecte un `<style>` à `document_start`, puis `insertCSS` de secours) ; **script personnalisé** (« Exécuté au chargement, dans un monde isolé » : `executeJavaScriptInIsolatedWorld` à `dom-ready`) ; **notifications** = `permissions.notifications` existant. Tests : vitest résolution (exacte > hôte > motif, champ par champ), migration du booléen, en-têtes cookies/CSP/UA sur des requêtes simulées ; e2e : règle Strict + style perso sur un site de test local → style présent au premier `DOMContentLoaded`, cookie tiers absent, UA alternatif vu par le serveur de test ; `@youtube` toujours vert.
